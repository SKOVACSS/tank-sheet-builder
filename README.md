# TankRounds (moved)

TankRounds now lives at **https://tanks.stevenks.com**.

This repository only keeps the old address, `skovacss.github.io/tank-sheet-builder`, working:

- `index.html` and `404.html` forward visitors to the new address, keeping share links (`#L=…`) and printed QR codes (`#s=…`) intact.
- `sw.js` replaces the old offline worker. Devices that used the old site delete their old offline copy and move to the new address.

Desktop and phone app downloads are published under this repository's **Releases**.
